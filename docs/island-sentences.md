# Language Islands — first 50 useful sentences

The everyday survival sentences a newcomer in Finland actually needs to say. These power the **Speaking practice** screen (topic slug `arki`).

**Verification status:**

- **Kirjakieli** (written): every word is **Voikko-validated** (real Finnish forms). Voikko checks morphology, not naturalness, so a Finnish speaker should still skim for phrasing.

- **Puhekieli** (spoken): **NOT auto-validated** — these are common Helsinki-region spoken forms I authored. **A Finnish speaker should verify these before they're treated as final.** Edit freely below.

To load into the app: run `supabase/seeds/05_island_sentences.sql` once in the Supabase SQL editor.
